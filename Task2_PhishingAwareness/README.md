# Task 2 – Phishing Awareness Training

Task 2 of the **CodeAlpha Cyber Security Internship**.

An awareness training module that teaches people how to recognize and avoid phishing attacks.

## Contents
| File | Description |
|------|-------------|
| `Phishing_Awareness_Training.pdf` | The training presentation (14 slides) |
| `Phishing_Awareness_Training.pptx` | Editable PowerPoint version |
| `Quiz_Questions.md` | 10 quiz questions with answers |

## Topics covered
- What phishing is and its channels (email, SMS, calls, social apps)
- Types of phishing: spear phishing, whaling, clone phishing, smishing, vishing, quishing
- 8 red flags of a phishing email, with an annotated example
- How to read a URL and spot fake websites
- Social engineering tactics: urgency, authority, fear, greed, trust, pretexting
- Real-world cases (Google & Facebook invoice fraud, Twitter 2020, 2016 campaign email hack)
- Everyday scam messages
- Best practices (Do's and Don'ts) and what to do if you clicked a phishing link
- Interactive "Phish or legit?" quiz

## Key takeaway
**Stop. Think. Verify.** Pause before you click, check the sender and the link, and confirm requests through an official channel.
